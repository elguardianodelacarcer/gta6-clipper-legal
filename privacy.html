GTA6 Clipper - Privacy Policy

Last updated: 17 November 2026

1. Overview

GTA6 Clipper is a desktop application that uploads gaming highlight videos to the connected user's own TikTok account as drafts. This policy explains what data the app handles.

2. Data we access

When a user connects their TikTok account, the app receives from TikTok:

  • Basic profile information (open id, display name, avatar) through the user.info.basic scope, used only to show which account is connected.
  • An access token and refresh token through the video.upload scope, used only to upload videos as drafts to that account.

3. How data is stored

Tokens are stored locally on the user's own computer, in a configuration file readable only by the user. They are never transmitted to any server other than TikTok's API. No analytics, tracking or third-party services are used.

4. Data we do not collect

The app does not collect, sell or share personal data. It does not read the user's TikTok videos, followers, messages or any data beyond the scopes listed above.

5. Deleting data

Users can revoke the app's access at any time from TikTok (Settings and privacy, Security, Manage app permissions). Deleting the local configuration file removes all stored tokens.
